# Claims and boundaries

## VERIFIED HERE

The public repository independently demonstrates:

- deterministic synthetic scenario evaluation;
- timeout → provider-readback decision behavior;
- replay containment in the public model;
- fail-closed handling of unknown provider state;
- settlement hold on incomplete/failed outcome evidence;
- deterministic proof-receipt verification;
- public CI/test behavior.

## ILLUSTRATIVE

All transactions, IDs, balances, failure events and business consequences in the demo are synthetic.

## PRIVATE / NOT DISTRIBUTED

The repository does not distribute production runtime/orchestration, payment adapters, credentials, persistence/recovery, exact production policy, private forecast/evaluation systems, model routing or product-specific economic logic.

## NOT YET PROVEN BY THIS REPOSITORY

This repository does not prove:

- buyer demand;
- repeat revenue;
- production-scale economics;
- generalized production readiness;
- private forecast advantage;
- live mainnet financial correctness;
- any quantified reduction in financial loss.

Public CI proves the public demonstrator — not the private product.
